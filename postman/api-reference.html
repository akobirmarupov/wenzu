Postmanda ishga tushirish

Ikkala faylni import qiling — token va ID'lar keyin o'zi saqlanadi.

  1. Import → postman/WENZU.postman_collection.json va postman/WENZU.postman_environment.json
  2. O'ng yuqoridagi environment tanlagichdan WENZU — Local ni tanlang
  3. base_url to'g'riligini tekshiring — standart http://127.0.0.1:8000
  4. 01 · Autentifikatsiya papkasida 1 → 2 → 3 → 4 so'rovlarini shu tartibda yuboring

Barcha javoblar shu ikki shaklda keladi.

Xato

{
  "success": false,
  "error": {
    "code": "bad_request",
    "message": "Parollar mos kelmadi.",
    "details": { "password_confirm": [...] }
  },
  "request_id": "a1b2c3d4e5f6"

  "count": 128,

  "current_page": 1,
  "next": "...?page=2",
  "previous": null,
  "results": [ ... ]
}

?page= va ?page_size= (max 100) bilan boshqariladi.

POST /api/auth/register/ ochiq

1. Ro'yxatdan o'tish

Yangi foydalanuvchi. Rol avtomatik user bo'ladi, telefon hali tasdiqlanmagan.

Request body
{
  "full_name": "Sardor Yusupov",
  "phone_number": "+998901234567",
  "username": "sardor_y",
  "password": "StrongPass123!",
  "password_confirm": "StrongPass123!"
}
POST /api/auth/send-code/ ochiq

2. SMS kod so'rash

Telefon raqamiga 6 xonali tasdiqlash kodi yuboriladi (Eskiz.uz orqali).

Request body
{
  "phone_number": "{{phone_number}}"
}
POST /api/auth/verify-phone/ ochiq

3. Telefonni tasdiqlash

Kodni tekshiradi va is_phone_verified=True qiladi.

Request body
{
  "phone_number": "{{phone_number}}",
  "code": "{{sms_code}}"
}
POST /api/auth/login/ ochiq

4. Kirish (login)

JWT token beradi VA foydalanuvchi ma'lumotini qaytaradi.

Request body
{
  "username": "{{username}}",
  "password": "{{password}}"
}
POST /api/auth/refresh/ ochiq

Tokenni yangilash

Access token 1 soat yashaydi. Tugagach shu endpoint bilan yangilanadi.

Request body
{
  "refresh": "{{refresh_token}}"
}
